# 泰語發音本（สมุดฝึกออกเสียง）

單檔網頁應用，用來整理泰語單字與句型、用語音合成反覆練習發音，並記錄每筆的播放次數。

## 功能

- **單字 / 句型** 兩個分頁，可依播放次數、隨機或最新排序，可限制顯示筆數、搜尋、隱藏。
- **發音**：使用瀏覽器 Web Speech API（`th-TH`），可調整語速；支援整份清單連續播放並設定間隔秒數。
- **從 PDF / 文字擷取**：用 pdf.js 讀取 PDF 文字（掃描檔改送頁面圖片），交給 Claude 挑出重要單字與句型（標準泰文、不附拼音），預覽確認後再存入。
- **備份**：匯出 / 匯入 JSON（含播放次數）。

## 執行環境

| 環境 | 資料儲存 | Claude 擷取 | 匯出備份 |
| --- | --- | --- | --- |
| claude.ai Artifact（具 `db`、`user`、`sample`、`downloads` 能力） | 雲端資料庫，跨裝置同步 | ✅ | ✅ |
| 一般瀏覽器直接開啟 / 靜態主機 | 瀏覽器 `localStorage`（僅限此裝置） | ❌（可手動新增） | ❌ |

本機預覽：

```bash
python3 -m http.server 8000
```

然後開啟 <http://localhost:8000>。

## 語音

Android 請在「設定 › 系統 › 語言 › 文字轉語音輸出」中下載 Google 語音服務的「泰文」語音資料；建議使用 Chrome。
